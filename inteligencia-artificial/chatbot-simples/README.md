# Chatbot Simples

Um chatbot básico desenvolvido em Python que utiliza processamento de linguagem natural simples para responder perguntas e manter conversas básicas.

## Funcionalidades

- Reconhecimento de padrões de texto
- Respostas contextuais
- Base de conhecimento expansível
- Interface de linha de comando
- Histórico de conversas

## Tecnologias utilizadas

- Python 3.6+
- Expressões regulares (regex)
- Processamento de texto básico

## Como usar

1. Execute o chatbot:
```bash
python chatbot.py
```

2. Digite suas mensagens e pressione Enter
3. Digite 'sair' para encerrar a conversa

## Exemplo de conversa

```
🤖 Chatbot: Olá! Eu sou um chatbot simples. Como posso ajudá-lo hoje?

Você: Oi, como você está?
🤖 Chatbot: Estou bem, obrigado por perguntar! Como posso ajudá-lo?

Você: Qual é o seu nome?
🤖 Chatbot: Meu nome é ChatBot Simples. Prazer em conhecê-lo!

Você: Me conte uma piada
🤖 Chatbot: Por que os programadores preferem o modo escuro? Porque a luz atrai bugs! 😄

Você: sair
🤖 Chatbot: Foi um prazer conversar com você! Até logo! 👋
```
