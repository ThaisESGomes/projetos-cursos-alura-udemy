# Projeto Python Simples

Este é um projeto Python simples para demonstrar conceitos básicos de programação, como variáveis, estruturas de controle e funções.

## Funcionalidades

- Calcula a soma de dois números.
- Verifica se um número é par ou ímpar.
- Exibe uma mensagem de boas-vindas personalizada.

## Como executar

1. Certifique-se de ter o Python instalado em sua máquina.
2. Navegue até o diretório `python-simples`.
3. Execute o script `main.py`:

```bash
python main.py
```

## Exemplo de uso

```
Digite o primeiro número: 10
Digite o segundo número: 5
A soma é: 15

Digite um número inteiro: 7
7 é ímpar.

Olá, ThaisESGomes! Bem-vindo(a) ao projeto Python Simples.
```
