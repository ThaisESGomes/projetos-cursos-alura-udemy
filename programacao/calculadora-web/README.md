# Calculadora Web

Uma calculadora simples desenvolvida com HTML, CSS e JavaScript para demonstrar conceitos de desenvolvimento front-end.

## Funcionalidades

- Operações básicas: adição, subtração, multiplicação e divisão
- Interface responsiva e intuitiva
- Validação de entrada
- Histórico das últimas operações

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)

## Como usar

1. Abra o arquivo `index.html` em seu navegador
2. Use os botões numéricos para inserir números
3. Clique nos operadores (+, -, *, /) para realizar operações
4. Pressione "=" para obter o resultado
5. Use "C" para limpar a tela
